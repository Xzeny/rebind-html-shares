Add another HTML file later

  1. Put the new self-contained HTML file in this repository’s root (or a clearly named folder).
  2. Add a card for it in index.html, with a short title and a link to the file.
  3. Include <meta name="robots" content="noindex,nofollow"> on every new page.
  4. Commit the files to the main branch. The public site updates after GitHub Pages (or the host listed in the README) rebuilds, usually within a couple of minutes.
