Install Rebind; it's free and runs locally.

In hardware mode, use a keyboard attached in Peripherals so the chord still reaches Rebind.

Software mode is free and needs no extra hardware. It remaps keys and buttons through the OS. It can't block mouse movement.

With Rebind Link, output leaves as real USB HID. A script can change the mouse's motion while your hand is still moving.

https://rebind.gg/products/rebind-link
Copied Open linked page

This is a build-log lesson from a documented product limit, not a documented personal failure. The site states the software-mode mouse limit; it does not tell a failure story. If you have a real anecdote (why this split exists, or a time the limit bit you), you can add it. I did not invent one. I also left 'up to 8,000 Hz' off this post to stay under 280; that figure is already in the November 24 draft, in Link context.

Sources for each claim
  • https://docs.rebind.gg/concepts/how-it-works — Rebind is free. Software mode needs no extra hardware. Rebind captures input through operating system hooks and sends output through the operating system's input APIs.
  • https://docs.rebind.gg/concepts/how-it-works — Transforming mouse movement, with a move handler or mouse_block=true, needs hardware mode; Rebind refuses to start such a script in software mode. Key, button, and scroll blocking work in both.
  • https://rebind.gg — Without Link, software mode reads input through your OS instead, and mouse movement can't be blocked there.
  • https://www.rebind.gg/products/rebind-link — Software can remap buttons. Link lets a script change the mouse's motion while your hand is still moving. Output: Real USB HID keyboard and mouse.
